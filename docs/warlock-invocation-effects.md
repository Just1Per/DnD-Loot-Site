# Warlock passive invocation effects

Choose invocations in Character Builder. The active effects are derived from the current rules edition, actual assigned Warlock level, prerequisites and allowed invocation slots. Editing, removing or lowering a class makes invalid choices inactive while keeping saved choices for recovery. The group has one help button; individual choice fields use hover/focus help.

| Invocation | Source | Sheet effect |
| --- | --- | --- |
| Devil's Sight | 2014 / 2024 | Separate 120-foot sight through magical and ordinary darkness in Overview Senses; 2024 also includes Dim Light |
| Witch Sight | 2014 | 30-foot true-form sight for qualifying creatures within line of sight |
| Witch Sight | 2024 | 30-foot Truesight |
| Beguiling Influence | 2014 | Automatic Deception/Persuasion proficiency, counted once; can qualify those skills for Expertise |
| Eyes of the Rune Keeper | 2014 | Reading ability shown in Invocation effects; spoken-language proficiencies are unchanged |
| Eldritch Mind | 2024 | Concentration-only Constitution-save advantage shown in Invocation effects and derived state |

Ordinary Darkvision remains separately calculated from species/items. Devil's Sight is not stored as an artificial increase to racial Darkvision. Eldritch Mind does not add a flat bonus or grant advantage to every Constitution save. A manual proficiency/Expertise marking is preserved when an invocation is removed; stale automatic sources do not keep granting proficiency.

Overview and printed Skills show the supported passive effects. Skill totals and training circles update automatically. Remaining casting invocations, chosen cantrips/weapons and additional source options stay explicitly partial in the level-by-level review; this change does not declare the entire invocation system complete.

Validation covers both editions and levels 1–20, actual multiclass caps, overflow slots, racial senses, Expertise overlap, scoped language/save benefits, save-envelope parity, browser save/reopen, print, removal and responsive accessibility.

Rules references: [2014 Basic Rules, classes](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/classes) and [2024 Basic Rules, classes](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes). These are concise mechanical facts and original UI descriptions, not a copy of source-book prose.

No Firestore or Storage rule changes. Effects are derived from existing saved choices; no production deployment or data migration is required.
