Changes: rules have been organized as structured data and shortened descriptions, with original website code that calculates selected effects. This builder uses the 2014 rules represented in SRD 5.1. It includes its nine races and listed subraces, all twelve base classes, and the Acolyte background. It does not include every option from all published books.

Other races, backgrounds, multiclass builds and homebrew can use manual entries. Features not explicitly calculated remain subject to the table’s rules and DM decisions.
